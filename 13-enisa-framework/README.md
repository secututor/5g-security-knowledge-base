# 13. EU 보안 프레임워크 (ENISA)

유럽 사이버보안청(ENISA, European Union Agency for Cybersecurity)의 5G 보안 자료입니다.
각 이슈 문서의 **관련 EU 가이드라인** 섹션에서 참조하는 `EU-N` 코드의 정의입니다.

> ENISA는 위협 전체 지형(Threat Landscape)을 조망하는 관점이 강합니다.
> 3GPP, ITU, ETSI, ISO, NIST, GSMA 등의 자료를 종합합니다.

---

## EU 코드 정의

| 코드 | 자료 | 다루는 문제 |
|------|------|-------------|
| **EU-1** | ENISA 5G Threat Landscape | 5G 자산·위협·취약점·공격 가능성·보안통제를 종합한 기본 위협 지형 자료 |
| **EU-2** | ENISA 5G Security Controls Matrix | 상세 보안통제 매트릭스 (399개 통제, 110개 자산 유형, 2개 5G 아키텍처, 3개 클라우드 배포 모델) |
| **EU-3** | ENISA Security in 5G Specifications | 3GPP 보안 규격과 주요 security control 해설 |

---

## 각 자료 설명

### EU-1 — 5G Threat Landscape
5G 아키텍처를 기준으로 UE / RAN / 5G Core / Network Slicing / NFV / SDN / MEC / Virtualization / Management·Orchestration / Supply Chain / Privacy / DoS 등을 다룬다.
분석 구조: **Asset → Vulnerability → Threat → Threat Agent → Impact → Security Control**.
→ "5G에 어떤 위협이 존재하는가"를 파악할 때 1순위.

### EU-2 — 5G Security Controls Matrix
"이런 위협이 있다"에서 끝나지 않고 **Threat → Security Control → 대응 방법**으로 연결한다.
스프레드시트 형태로 제공되어 보안 평가/컨설팅에 활용도가 높다.
→ 위협에 대응하는 통제를 매핑할 때 사용.

### EU-3 — Security in 5G Specifications
3GPP 보안 규격(TS 33.501 등)에서 정의된 보안 기능과 통제를 이해하기 위한 자료.
→ 표준의 보안 메커니즘을 해설할 때 사용.

## 저작권 / 출처 표기 (중요)

ENISA 자료는 공개되어 있고 재사용이 **원칙적으로 허용**되지만, 조건이 있다.

1. **출처를 명확히 표시**한다.
   예: `Source: European Union Agency for Cybersecurity (ENISA), "ENISA Threat Landscape for 5G Networks", 2020.`
2. **ENISA 원문과 작성자 해설을 구분**한다. (작성자 분석을 ENISA 공식 입장처럼 보이게 하지 않는다)
3. **ENISA 로고는 사용하지 않는다.** 텍스트 출처 표기만 사용.
4. **ENISA 문서 내 제3자 자료(사진·그림 등)는 별도 저작권** — 그대로 복사하지 말고 직접 새로 그린다.

일부 자료는 **CC BY 4.0**으로 명시되어 있어 출처표시 + 변경사항 표시 하에 재사용·수정이 가능하다.
